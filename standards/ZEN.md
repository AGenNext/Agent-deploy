# The Zen of OpenAutonomy

```
Meaning is a contract.
One word, one meaning.
The prompt is over; the instruction begins.

Two can act; only three can be trusted.
No one approves their own work.
Verify before you trust.

Now → next — never further.
Every loop must resolve.
Good enough beats perfect — then loop again.

Only data is real.
The contract governs; code conforms.
A node is where edges meet.

Every surface needs a protocol.
Govern the gate, not the process.
Govern, but never cage.

Define the tangible; leave the rest unsaid.
Anchor to what exists; build the next edge.
Balance is kept, not reached.

Open the gates — and keep the third.
It is a human world; agents are guests.

Strive for better — in a loop.
```
