## Project maturity levels (cf. CNCF Sandbox / Incubating / Graduated)

| level | meaning | gate |
|---|---|---|
| **Sandbox** | experimental; no guarantees | basic doc set started |
| **Incubating** | in real use; growing | passes validation; gated |
| **Graduated** | production-ready; widely adopted | passes **all** gates; outcomes proven |

Honest current mapping (from the AGenNext survey): **Sandbox** = the empty/early
repos; **Incubating** = the active ones (Agent-Site, Agent-Platform, Agent-IDE,
Code-Review, Agent-Harness, …); **Graduated** = none yet.

## Adoption maturity model (cf. CNCF Cloud Native Maturity Model)

Stages for an organisation adopting the agent stack:

1. **Build** — define meaning; first instructions.
2. **Operate** — run governed agents (the harness).
3. **Scale** — many agents; verified handoffs.
4. **Improve** — measure outcomes (CLEAR); tune.
5. **Optimise** — balanced, federated, global scale.

---

## Governance ties

**Maturity = passing gates.** A project *graduates* by meeting the standard
documentation set (`repo-boundaries.md`), passing `Agent-deploy` validation, and
proving outcomes — **verified by the third, ratified by quorum.** Maturity is
earned stage by stage, never granted ahead of evidence (the agent lifecycle).
